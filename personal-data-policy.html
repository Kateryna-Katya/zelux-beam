Personal Data Processing Policy

1. General Provisions

This Personal Data Processing Policy (hereinafter — the "Policy") defines the procedure and conditions for processing personal data undertaken by the Zelux Beam platform (hereinafter — the "Operator") and establishes measures to ensure the security of this data.

1.1. The Operator considers the observance of human and civil rights and freedoms when processing personal data, including the protection of the right to privacy, personal and family secrets, as its most important goal and condition for its activities.

1.2. This Policy applies to all information that the Operator may receive about visitors (hereinafter — "Users") of the website zelux-beam.blog.

2. Basic Concepts Used in the Policy

  • Website — a collection of graphic and informational materials, as well as computer programs and databases that ensure their availability on the Internet at zelux-beam.blog.
  • User — any visitor to the website.
  • Personal Data — any information relating directly or indirectly to a specific or identifiable User of the website.
  • Processing of Personal Data — any action using automation tools or without them, including collection, recording, systematization, accumulation, storage, clarification, use, and destruction of data.
  • Personal Data Security — protection of data from unauthorized or accidental access, destruction, or copying.

3. Data We Process

The Operator may process the following categories of data:

  • Personal Data provided by the User:
    • Last name, first name, middle name;
    • Email address (Email);
    • Phone numbers (for communication and validation).
  • Data collected automatically:
    • Anonymized data about visitors ("cookies") using Internet statistics services (Google Analytics and others). This data includes IP address, browser type, and access time.

4. Purposes of Personal Data Processing

  • Identification of the User to provide access to educational services.
  • Establishing feedback, including sending notifications and processing course applications.
  • Conclusion and execution of educational contracts.
  • Informing the User through newsletters. The User can opt-out by writing to support@zelux-beam.blog with the subject "Unsubscribe".
  • Improving the quality of the IT school and analyzing content demand.

5. Legal Grounds for Processing

The Operator processes data only with the voluntary consent of the User, expressed through filling out forms on the zelux-beam.blog website, and if permitted by the User's browser settings (cookies).

6. Storage and Security Procedures

  • The Operator takes all technical measures to protect data from unauthorized access.
  • Data is never transferred to third parties, except in cases of compliance with EU legislation.
  • The processing period is unlimited, but the User can withdraw consent at any time via the Operator's email.

7. Final Provisions

  • The User can receive clarifications on any questions by writing to: support@zelux-beam.blog.
  • The current version of the Policy is always available on the Zelux Beam website.
